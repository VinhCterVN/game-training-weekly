# tube levels - lab 2

water sort game for week 3. made with unity 2022.3.62f2
there are 5 levels, sort the colors until each tube has only one color in it.

## how to play

- open the project and wait for unity to import stuff
- open `Assets/Scenes/MainScene.unity`

click a tube then click another one to pour. the other tube needs to be empty or have the same color on top. each tube holds 4 pieces.

undo = go back one move

restart = start that level again
levels = choose an unlocked level
sound on/off = mute the sounds

finish a level and click next level. after level 5 it goes back to level 1.
it saves your current level and unlocked levels, but the water arrangement starts over when you reopen the game.

windows build is at `Builds/Windows/TubeLevels.exe`. keep the data folder and dll files next to it.

level stuff
----------

level files are in `Assets/ScriptableObjects/Levels`
select one to edit it in the inspector. colors go from bottom to top, dont put more than 4 in a tube.

- generate random solvable level: makes a puzzle using the seed and checks it can be solved
- validate level : checks the colors, empty tubes and looks for a solution. if the search runs out it doesnt always mean the level is impossible
- arrange bottles: puts them into rows
- clear data : removes the bottle list, ctrl+z can undo it

level 1 = 4 tubes / 3 colors

level 2 = 5 tubes / 4 colors
level 3 = 7 tubes / 5 colors
level 4 = 8 tubes / 6 colors
level 5 = 9 tubes / 7 colors

use 4 pieces of each color and leave 1 or 2 tubes empty.
the pool has 10 bottles so keep it at 10 or less. the level selection screen is set up for 5 levels.

database: `Assets/ScriptableObjects/LevelDatabase.asset`

## scripts etc

`LevelManager` loads levels and saves progress

`ObjectPooler` makes 10 bottles at the start and reuses them
`BottleController` handles the bottle images and pouring animation
`WaterSortController` handles selecting tubes, pouring rules, undo and winning

`UIManager` and `WinPopupUI` handle the buttons and popup.
`AudioManager` plays click, pour, complete, win and error sounds
`LevelDataSO` holds the level data. `LevelSolver` is used for generating and checking puzzles.

bottle prefab: `Assets/Prefabs/Bottle.prefab`
it has the glass, 4 water images, selection image and mouth point inside it. water pieces are child images in the generated version.

the pour uses the mouth points to line up the tubes. tweens get stopped when a bottle is returned to the pool or destroyed. the little completion particles are reused too.

there can still be some memory allocation from text and animations. the pooling is for avoiding new bottles every time you restart or change levels.

checking / rebuilding

- menu: Tube Levels > Run Logic Verification
  results go in `Logs/logic-verification.txt`

- Tube Levels > Build or Repair Game Scene
  this rebuilds the scene and bottle prefab. it keeps the level data, but overwrites manual scene and prefab edits so dont use it after customizing those unless you want to rebuild them.

the old scene backup is in `Tools/Backups/MainScene.before-lab2.unity.txt`

for the automatic player test, launch the development exe with `-batchmode -lab-smoke`. it plays all 5 levels and checks undo, next level and the pool. screenshots and results go in the `QA` folder beside the exe. it uses separate test save keys.
